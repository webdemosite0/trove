# Tros transparent icon concepts

36 separate PNG icons generated with the built-in image-generation tool. These are raster design assets, not SVGs or animations.

Charcoal is used for standard icons; violet is used for the selected-state examples shown in the concept sheet. Because icons were generated individually, small differences in geometry and optical weight may remain. For production UI, recreate them in a consistent SVG grid.

## Generation prompt

Each icon was generated using its filename's role and corresponding geometric symbol, with this common direction: one isolated premium Tros rounded monoline icon; charcoal #111827 or violet #6334FF; uniform 2px-looking stroke at a 24px reference scale; round caps and joins; simple flat vector-like geometry; centered on a square canvas at approximately 70% size; genuinely transparent background; no text, labels, shadows, glow, or background tiles.

## Motion

Use SVG for small UI transitions and state animations. Use layered character artwork and a state-machine animation tool for agent avatars. These PNGs can be faded, translated, or rotated, but their individual strokes are not independently editable.
